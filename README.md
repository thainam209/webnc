## Ảnh demo giao diện nằm trong chương 4 của báo cáo: file bcao webnc.docx
## Hướng dẫn chạy dự án (Cài đặt môi trường cho php)
Bước 1: Cài đặt xamp -> start apache và mysql
Bước 2: Mở giao diện mysql bằng lệnh localhost/phpmyadmin và import file sql nằm trong thư mục database
Bước 3: Chạy dự án bằng lệnh localhost/tên thư mục ví dụ localhost/bookhotel
### Lưu ý:
Folder dự án phải được nằm trong đường dẫn thư mục sau: xamp/htdocs/
Trong file dbconfig.php tên database, pass, hname(hostname)=localhost phải được đặt đúng
